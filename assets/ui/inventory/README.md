# Inventory artwork

`case_lining_v01.png` is the original charcoal case lining, generated with the
built-in ImageGen tool. Exact prompt: `case_lining_v01.prompt.txt`. It is kept
as source artwork; the current Dino Crisis 2-inspired inventory draws its
metal panels, grid, focus brackets, condition monitor and controls in Godot.
The deterministic steel texture is generated by `ui/inventory_console.gd`.

`dylan_portrait.png` is a head-and-shoulders render of the same Mixamo-rigged
Dylan model used in gameplay, lit and framed by `tools/render_inventory_portrait.gd`.
Run that script with Godot Compatibility, then reimport the PNG in the editor.

The active portraits are `pistol_v06.png`, `shotgun_v06.png`,
`handgun_ammo_v06.png`, `shotgun_shells_v06.png` and `med_kit_v06.png`.
They were created with the built-in ImageGen tool to follow the user's
`style_reference_v06.png`: worn, textured pre-rendered survival-horror objects
with three-quarter depth, subdued colors and directional highlights.
Each asset has a transparent background; borders and quantities remain native UI.
Exact prompts, input roles and tool provenance are in `icons_v06.prompts.json`.

`pistol.png` and `shotgun.png` remain as source silhouettes baked from the
actual game models with `tools/render_inventory_icons.gd` using Godot
Compatibility. Changing UI portraits does not change the equipped 3D models.

The 16:9 UI fits portraits to their measured opaque bounds (alpha >= 0.25 plus
eight pixels of padding), recorded alongside the versioned images in
`InventoryArt.PORTRAIT_REGIONS`. Faint transparent halos do not reduce the
apparent size of the item, and no image scan runs when opening the menu.
Supplies use the same
textured portrait path. Grid, equipped-weapon panel and inspection previews
share this aspect-preserving fit, including rotated items. Source PNGs stay intact.

Reproduce the weapon portraits:

```powershell
& '.tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe' --path . --rendering-method gl_compatibility --script res://tools/render_inventory_icons.gd
```
