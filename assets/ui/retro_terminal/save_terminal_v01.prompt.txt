Use case: ui-mockup.

Buttons dominate over decorative details, clearly readable at reduced scale. Industrial grid and subtle checker dithering in the background.
Palette: deep charcoal teal, muted steel blue, desaturated cyan-green, pale mint highlights, a single restrained amber online indicator.
Exact text only, clean and spelled verbatim: top title "LIMIAR"; below "SAVE TERMINAL"; primary buttons "SAVE" and "SHOP"; small "EXIT"; right panel "SYSTEM STATUS", "ONLINE", "GUARDHOUSE", "RECORD 01", "DATA READY"; footer "[ENTER] CONFIRM    [ESC] BACK".
Constraints: One coherent screen, all text horizontal, no perspective distortion. Professional game UI concept, faithfully understated old computer aesthetic.
